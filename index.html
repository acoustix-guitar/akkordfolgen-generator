Sound options and limits

The five built-in instruments are synthesised with oscillators, filters and envelopes. They are not recordings of real instruments and work fully offline.

Optionally you can add a sample pack. It is played by pitch-shifting your audio files, so each file name must contain a note name, for example piano_C4.wav, F#3.mp3 or Bb2.ogg. Samples must be WAV, MP3, OGG or another format your browser can decode.

.sf2 SoundFonts cannot be played – this single-file app contains no SoundFont parser. Please export samples from your SoundFont as individual audio files named by note.

The server option only works when this page is served over http(s) and a manifest exists at /soundfonts/manifest.json in the form {"name":"My pack","samples":[{"note":"C4","file":"C4.wav"}, …]}. Files are fetched from /soundfonts/ only when you press the button; nothing is loaded silently and no directory listing is attempted.
